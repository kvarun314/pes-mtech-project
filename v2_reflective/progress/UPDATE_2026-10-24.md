# Status update, 2026-10-24 (facts for the user to rewrite in their own words)

## Done since Oct 22
- Six experiment phases were run, each with a rule fixed beforehand and checked on development data only:
  - C: LoRA trained on 10K rows. FAIL.
  - F: hidden-state probe. FAIL.
  - D: pooled-dev Reflector. Passed its gate, but not adopted because the gain was a class-prior shift.
  - F2: multi-layer probe. FAIL.
  - G and G2: 500K-row Evidence agent. FAIL in the stack, but better on its own.
  - H: bigger dev set and bigger probe fit. PASS.
- Polarity paired CIs: the stack is significantly better than each single agent on polarity, on both test splits.
- Phase H is now the main configuration (SH): a frozen base-LLaMA layer-20 probe plus a 500K TF-IDF Evidence agent, combined by an LR Reflector.

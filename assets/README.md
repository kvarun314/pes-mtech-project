# Assets for presentations

## Phase 2 architecture diagram

To have the **Phase 2 multi-agent architecture** appear in the PPT and HTML:

1. Copy your architecture image (e.g. the LangGraph diagram) to this folder.
2. Name it **`Phase2_Architecture.png`**.

Then run:

- `python create_agentic_presentation.py` — the slide "Proposed System: Phase 2 Multi-Agent Architecture" will include the image.
- Open `Agentic_Sentiment_LLaMA3.html` in a browser — the diagram will show in section 10.

If the file is missing, the PPT shows placeholder text and the HTML will show a broken image until you add the file.
